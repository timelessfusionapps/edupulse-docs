## Purpose
Summarize the structural evolution of the Student Management UI.

## Key Additions
- **constants/**: Centralized layout constants to eliminate magic numbers.
- **layouts/**: A dedicated orchestrator (`responsive_student_layout.dart`) separates breakpoint detection from actual rendering.
- **adaptive/**: Widgets that inherently know how to mutate across breakpoints (e.g., dropdowns becoming bottom sheets).

## Scalability
This directory structure isolates concerns, allowing future modules like `Teachers` to clone this architecture verbatim.
