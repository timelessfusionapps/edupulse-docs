## Purpose
Defines the visual behavior of the search bar.

## Operational Assumptions
- **Placement**: Prominently pinned above the table/list, expanding on focus.
- **Debouncing**: To prevent Firestore read exhaustion, search input must be debounced by ~500ms before firing the query.
- **Clearance**: A trailing 'X' icon appears when text is entered to quickly clear the search and reset the stream.
- **Loading Indicators**: While debouncing/fetching, a subtle linear progress indicator or a spinning search icon appears inside the text field.
- **Keyboard Safety**: On mobile, submitting the search or tapping outside must reliably close the soft keyboard to prevent UI obstruction.
