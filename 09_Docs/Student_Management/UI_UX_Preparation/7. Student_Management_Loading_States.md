## Purpose
Defines the visual feedback mechanisms during asynchronous operations.

## Initial Load (Skeleton Screens)
- Instead of a jarring blank screen with a centered spinner, we will display a skeleton structure matching the final layout (a skeleton table on desktop, skeleton cards on mobile).
- Skeletons use a subtle shimmering animation.

## Realtime Updates & Reconnects
- Since we use streams with `includeMetadataChanges: true`, the UI will update instantly from cache.
- When the app is syncing pending writes, a subtle "Syncing..." banner or icon may appear in the App Shell, avoiding disruption of the primary Student List.

## Error States
- Non-intrusive error cards with a "Tap to Retry" button. Never trap the user in an unrecoverable red screen.
