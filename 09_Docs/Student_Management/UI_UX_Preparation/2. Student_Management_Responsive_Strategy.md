## Purpose
Defines the strict rules for cross-form-factor scaling (390px to 1440px) to guarantee zero RenderFlex overflow errors.

## Responsive Breakpoints
1. **Desktop (1024px - 1440px+)**
   - *Layout*: Full width Data Table.
   - *Filters*: Permanent side-panel or persistent horizontal top-bar.
   - *Actions*: Inline icons on table rows.
2. **Tablet (768px - 900px)**
   - *Layout*: Condensed Data Table (collapsing non-essential columns like 'Section' into a subtitle under 'Grade').
   - *Filters*: Horizontal top-bar scaling to a dropdown if constrained.
   - *Actions*: Icon-only buttons or an ellipsis (kebab) menu.
3. **Mobile (390px - 600px)**
   - *Layout*: List of `StudentCard` widgets. 
   - *Filters*: Hidden behind a "Filter" Floating Action Button or top-right icon, opening a bottom sheet.
   - *Actions*: Swipe-to-action on cards or an ellipsis menu.

## Zero Overflow Tolerance
Overflows typically happen when text scales unexpectedly. All text inside constrained boxes will utilize `TextOverflow.ellipsis` and `maxLines: 1` or `2`. Wrap widgets will be used instead of Rows where horizontal space is dynamic.
