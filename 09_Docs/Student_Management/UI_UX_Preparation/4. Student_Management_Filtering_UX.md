## Purpose
Defines how users filter large datasets efficiently without complex modal dialogs on desktop.

## UX Architecture
- **Pill/Chip Filters**: Quick-select filter chips for immediate visual feedback. E.g., [Active], [Archived], [Grade: 10].
- **Dropdowns**: For lists with many options (e.g., Houses).
- **Instant Application**: Filtering should trigger an immediate repository request (debounced) rather than requiring an explicit "Apply" button, ensuring the UI feels snappy and reactive.
- **Empty States**: If a filter combination yields zero results, a dedicated `NoResultsEmptyState` will appear explaining *why* (e.g., "No archived students found in Grade 10") with a "Clear Filters" button.

## Mobile Adaptation
Filter chips take up too much horizontal space. On mobile, a "Filter" icon opens a standard `ModalBottomSheet` containing the same logic, applying the state upon dismissal.
